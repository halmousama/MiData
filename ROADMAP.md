## Why this is not 1.0 yet

Honest list, in the order it hurts:

1. **There is no application.** The repository currently contains a constitution, a plan, a behaviour
   specification and a documentation system. No Rust source exists — by design (BOOTSTRAP-1 was
   documentation-only), but it means every capability in `docs/inventory.md` is `planned`.
2. **No gate exists yet.** Without `xtask` + CI (P0-1), "never crash", layering and the file budget are
   intentions rather than enforced facts. This is the highest-ranked gap for that reason.
3. **Legacy parity is unmeasured.** `docs/testing.md` maps zero oracle scenarios until the authorized
   extraction session (P0-11) runs; until then acceptance criteria are written fresh from the plan
   (allowed by D15, but parity coverage is a number we cannot yet quote).
4. **The constitution is 4× over budget.** `AGENTS.md` is 32.7 KB against the plan's ≤ 8 KB target
   (P0-10) — a context-economy problem that taxes every session.
5. **No packaging, no release process in code.** Installers, tags and the release checklist are Phase 7;
   nothing is shippable before then.
