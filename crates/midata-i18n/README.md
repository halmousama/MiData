# midata-i18n

L0 · pure · no I/O. The string layer: two TSV catalogues embedded at build time, one lookup, one
coverage measurement — shared by the egui shell, the CLI and engine-side error messages (D3, D24).

`docs/i18n.md` is the authoring contract; this README is the API contract.

**Dependencies:** `serde` (the persisted `Language`/`CatalogueName` code) and `thiserror` (the
`CatalogueError` enum) — nothing else. No `egui`, no filesystem access at runtime.

## Catalogues

`catalogues/en.tsv` is the **source**; `catalogues/fr.tsv` is first-class. One row per line,
`key<TAB>text`, keys in `area.subject`, sorted, `{placeholder}` for params. Both files are pulled in
with `include_str!` (`EN_TSV` / `FR_TSV`), so there is no "translation file missing" failure mode and
no runtime file read.

The gate (`cargo xtask i18n-coverage`, `xtask/src/i18n/gate.rs`) has four teeth:

1. an **orphan FR key** (present in FR, absent in EN) is fatal — delete a dead row, do not park it;
2. an **unused EN key** (no `crates/`/`apps/` source contains the key as a quoted literal) is fatal —
   a speculative key is a dead key;
3. the **EN total may not shrink** — deleting EN rows lowers the coverage denominator;
4. **missing FR keys may not grow** — the translation ratchet.

The measured state lives in `docs/i18n-coverage.baseline` (generated by
`cargo xtask i18n-coverage --write-baseline`). A key must be a **literal at its call site**; building
keys with `format!` is unsupported by design, because it makes the usage scan and agent greps blind.

## Public API

| Item | Signature | Notes |
|---|---|---|
| `Catalogue` | `Catalogue::embedded() -> Result<Self, CatalogueError>` | Parses both embedded catalogues once, at the composition root. |
| | `Catalogue::from_tsv_pair(en: &str, fr: &str)` | The same parse from arbitrary text — how tests build a catalogue. |
| | `Catalogue::get(language, key) -> Option<&str>` | One lookup, no fallback chain. |
| | `Catalogue::en_keys()`, `coverage() -> Coverage` | Source keys and the measured gap, in-process (cheap; no file scan). |
| `CatalogueError` | enum | `MalformedRow` (a row with no tab, or an empty key) / `DuplicateKey` (the same key twice in one catalogue). A missing FR row is coverage data, never a parse error. Never panics. |
| `CatalogueName` | enum | `En` / `Fr` — which file a parse problem came from. |
| `Coverage` | `translated_fr()`, `fr_percent()` | `fr_percent` divides by the **EN total**, so an orphan row cannot make the fraction and the percentage disagree. |
| `Language` | `ALL`, `code()`, `from_code()`, `next()` | Closed set of two (`en`, `fr`), default `En`; persisted as the lowercase code. |
| `Translator` | `Translator::new(&catalogue, language)` | Holds a borrowed catalogue — no global state, no `static`. |
| | `t(key) -> &str`, `format(key, &[(name, value)]) -> String`, `has(key) -> bool` | A miss renders the **key itself** — never a panic, never an empty string. |
| `t!` | `t!(translator, "err.value.type_mismatch")` | Thin call to `Translator::t`. |
| `tf!` | `tf!(translator, "key", "min" => "1", "max" => "10")` | Substitutes `{placeholder}`s; values are `&str`, so the catalogue never decides how a number looks. |

## The translator is injected, not global

`docs/architecture.md` §9 forbids process globals, so the language travels as an argument:

```rust
use midata_i18n::{Catalogue, Language, Translator, t, tf};

let catalogue = Catalogue::embedded()?;
let translator = Translator::new(&catalogue, Language::Fr);

assert_eq!(t!(translator, "err.value.number_not_finite"), "Un nombre doit être fini.");
let text = tf!(translator, "err.pedigree.generations_out_of_range", "min" => "1", "max" => "10");
```

That is why the macro is `t!(translator, "key")` rather than `t!("key")`: a test renders any language
without touching a process-wide switch, and a snapshot harness can render EN and FR side by side.
Commands that fail return a `CommandError` carrying the **key** (`err.*`), and the surface that shows
the message translates it — so the engine never needs to know the UI language.

## Conventions

- Keys: `area.subject[.qualifier]`, lowercase, ASCII, dots only (`cmd.animal.create.title`,
  `screen.animals.empty`). Command *titles* are `cmd.*`, screens are `screen.*`, errors are `err.*`.
- User text never contains a machine token: params carry the machine value for agents, the sentence
  stays readable for the farmer.
- Seed a string when a screen or command needs it — never before. Speculative keys fail the gate.
- English and French are both first-class: a changed EN string that shifts meaning needs its FR row
  in the same change.
